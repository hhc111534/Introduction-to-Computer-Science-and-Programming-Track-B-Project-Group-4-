# AI Coding Rules

- Read `docs/architecture.md` and `docs/data-model.md` before changing code.
- Work only inside the module named in the task.
- Do not change shared interfaces in `paperlens/common/` without review.
- Add or update tests for every behavior change.
- Never print, commit, or paste API keys, private papers, or user data.
- Keep functions small and typed; prefer explicit inputs and outputs.
- Run the relevant tests before opening a pull request.
