# AI Usage Log

**When to fill it in:** on the same day as the AI-assisted work, and before merging the pull request.
**Who fills it in:** the member who used the AI tool.
**Who reviews it:** the teammate who reviews the pull request.

## Rules

- Record one row per task or pull request, not one row per prompt.
- Link the row to the pull request or commit.
- Describe the scope briefly; do not paste full proprietary prompts.
- Never put API keys, private papers, unpublished data, or personal information in this log.
- The human reviewer confirms that the code was tested and understood.
- If the course requires a separate AI-use declaration, export this file or attach it to the final report.

## Where else to mention AI use

1. **Pull request:** tick the "AI-assisted" box in the PR template and link the log row.
2. **Final report:** add a short "AI Assistance" section summarizing tools, scope, and human review.
3. **Demo/defense:** be ready to explain which parts were AI-assisted and how they were verified.
