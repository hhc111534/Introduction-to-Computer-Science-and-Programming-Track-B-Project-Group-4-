# 人工开发日志

本文件按时间顺序记录所有成员的人工开发进展，**不按成员分节**。AI 使用记录请填写在 [`docs/ai-usage.md`](ai-usage.md)。

## 填写规则

- 每次开发或小组讨论后追加记录，按日期从早到晚排列。
- 同一天有多条记录时，按实际完成顺序排列。
- 每条记录写清完成内容、遇到的问题和下一步。
- 同一项工作由多人完成时，在“成员”列写清所有参与者。
- 不记录 API Key、未公开论文、个人隐私或完整敏感数据。
- 新增记录追加在表格末尾。
